# Internal linking architecture

- Homepage links to all ten hotel profiles in crawlable HTML, alongside regional pages, comparison, guides and methodology.
- North/South/Central pages list the matching properties and link back to the region comparison and homepage.
- Every profile links to the shortlist, North/South hubs and region comparison; contextual alternatives are linked in the profile body.
- Regional guide links to named properties and corresponding region hubs. The area guide leads to region hubs and trip-planning questions.
- Footer links to every trust/policy page on all routes.
- Comparison table links each hotel name to its profile.

Use descriptive labels (hotel/property names, region names, and decision language). Do not create filter URLs or query combinations as indexable routes. Search/filter state is client-only; canonical pages remain the static route.
