# Content guidelines

## Editorial standard

Write original, practical English for trip planning. Distinguish fact from recommendation. Prefer a specific limitation over generic praise. Do not claim firsthand experience, audits, rankings by users, credentials, prices, star class, awards, review aggregates or availability without dated attributable evidence. Make no unsupported distance or travel-time claims.

## Sourcing

Use official property and government sources first. Link the evidence near relevant content. Record the source URL and last verification date in each hotel data object. If a fact is not verified, omit or qualify it and record the gap. Third-party review data must have the source, collection date, count, and permitted use documented before considering it. For images, record the depicted property, creator, source URL, capture date where known, reuse license/permission, and required credit. Never infer rights from a filename or image appearance.

## Page templates

- **Homepage:** purpose and scope; selection disclosure; top ten early; filter/compare tools; regional links; methodology; useful FAQ.
- **Regional page:** region’s distinct travel context; only matching researched hotels; profile links; links to area guides.
- **Hotel profile:** property name and area; intended fit; official-source facts; verified facilities; trade-offs; official source/booking link; check date; relevant alternatives.
- **Guide:** answer the decision question first; use a table only when it clarifies choices; connect recommendations to relevant hotel profiles; state limitations.
- **Trust page:** plain description of sourcing, editorial process, corrections and relationships.

## Publication checklist

- Verify name, current official page, locality and each material facility.
- Confirm claim/source correspondence and update the checked date.
- Explain a genuine fit and a practical trade-off.
- Review route uniqueness, title, description, one H1, headings and internal links.
- Confirm no placeholder contact or site URL remains; do not publish ratings/prices without evidence, and clear image rights and required credits.
- Check mobile layout, keyboard access, filter/compare controls and external destinations.
- Recheck all claims after material hotel changes.
